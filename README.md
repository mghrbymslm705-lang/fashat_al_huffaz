# 📱 فسحة الحفّاظ

تطبيق **تربوي وترفيهي** موجّه لمعلمي حلقات تحفيظ القرآن الكريم.
مكتبة رقمية منظمة من **الألعاب والأنشطة والمسابقات والبرامج التربوية** تساعد المعلم
على تنشيط الحلقة وإدخال المتعة على الطلاب مع المحافظة على الطابع الإسلامي.

> ⚠️ **ملاحظة مهمة:** التطبيق **لا يخلق ولا يعدّل أي نشاط** من تلقاء نفسه.
> جميع المحتوى يأتي من ملفات **JSON** تضعها أنت. وظيفة التطبيق: تنظيم المحتوى،
> تصنيفه، البحث فيه، تصفيته، عرضه، وفتح روابط الشرح التي تضيفها أنت فقط.

---

## ✨ المميزات

- 🏠 **صفحة رئيسية** ببطاقات أقسام كبيرة وجميلة.
- 📖 8 أقسام جاهزة: الأنشطة القرآنية، الإسلامية، الألعاب الحركية، ألعاب الذكاء،
  الألعاب الجماعية، المسابقات الثقافية، ألعاب الأطفال، البرامج التربوية.
- 🔍 **بحث لحظي** داخل كل الأنشطة (مع تطبيع للعربية: التشكيل، الألف، الهاء، الياء).
- ⭐ **مفضلة** محفوظة على الجهاز.
- 🎛️ **فلاتر ذكية**: العمر، المشاركون، المدة، داخل/خارج القاعة، هادئة/حركية، بأدوات/بدون.
- 🎲 **المساعد الذكي "اقترح لي نشاطًا"**: يسأل المستخدم (عدد الطلاب، الأعمار،
  المدة، المكان، الأدوات، نوع النشاط) ثم يقترح **من داخل قاعدة البيانات المحلية فقط**.
- 📤 **استيراد المحتوى**: من ملف JSON مباشرة أو من مجلد الاستيراد داخل التطبيق،
  مع **منع التكرار** وتحديث الإصدارات الأحدث.
- 🌙 **الوضع الليلي** + تكبير/تصغير الخط.
- 💾 **يعمل دون إنترنت** — الإنترنت يُستخدم فقط لفتح روابط الشرح.
- 🧩 **قابل للتوسع**: أضف آلاف الأنشطة بمجرد إضافة ملفات JSON دون تعديل الكود.

## 📥 إضافة المحتوى (أهم جزء)

المصدر الوحيد للأنشطة هو ملفات JSON. طريقتان لإضافتها:

### الطريقة 1 — داخل الأصول (تُضمَّن مع التطبيق)

ضع ملفاتك في:

```
assets/data/activities/
```

أي ملف `*.json` يوضع هنا **يُحمَّل تلقائيًا** مع التطبيق دون تعديل الكود.

### الطريقة 2 — الاستيراد من داخل التطبيق

1. افتح **الإعدادات ← استيراد المحتوى**.
2. اختر ملف JSON، أو ضع الملف في **مجلد الاستيراد** داخل مستندات التطبيق
   واضغط "استيراد من مجلد الاستيراد".
3. عند الاستيراد:
   - تُمنع الأنشطة المكررة (بنفس المعرّف `id`).
   - يُحتفظ بالإصدار الأحدث (بمقارنة حقل `version`).

### بنية ملف النشاط

```json
{
  "id": "q-001",
  "title": "سباق حفظ السورة",
  "category": "quranic",
  "types": ["قرآني", "جماعي"],
  "description": "وصف مختصر",
  "goal": "الهدف التربوي",
  "participants": { "min": 4, "max": 20 },
  "age": { "min": 6, "max": 12 },
  "duration": { "min": 10, "max": 15 },
  "movement": "حركية",
  "location": "داخل",
  "tools": ["سبورة", "علامات"],
  "steps": ["خطوة 1", "خطوة 2"],
  "benefits": ["فائدة 1"],
  "tips": ["نصيحة 1"],
  "tags": ["حفظ", "مراجعة"],
  "videoUrl": "https://...",
  "source": { "file": "activities/q-001.json", "name": "الكتاب", "page": "10" },
  "favorite": false,
  "version": 1
}
```

- 📄 شرح كل حقل بالتفصيل في [`docs/SCHEMA.md`](docs/SCHEMA.md).
- 🧩 ملف القالب جاهز في `assets/data/activities/template.json`
  ويمكن تصديره من التطبيق (الإعدادات ← استيراد المحتوى ← تصدير قالب).

## 🔒 سياسة إدارة المحتوى (إلزامية)

التطبيق يلتزم حرفيًا بهذه القواعد:

1. لا ينتج التطبيق أي لعبة/نشاط من تلقاء نفسه (بدون ذكاء اصطناعي للمحتوى).
2. جميع الأنشطة مصدرها ملفات JSON التي تضيفها أنت فقط.
3. وظيفة التطبيق: استيراد، قراءة، تصنيف، تنظيم، بحث، تصفية، عرض، وفتح روابط الشرح.
4. ميزة **"اقترح لي نشاطًا"** تبحث **داخل قاعدة البيانات المحلية فقط**.
5. إذا لم يوجد نشاط مطابق تظهر الرسالة:
   > **«لا يوجد نشاط يطابق المعايير المحددة داخل قاعدة البيانات الحالية.»**
6. كل نشاط يحتفظ بمرجعه (الملف/الكتاب/الصفحة) ويُعرض في صفحة التفاصيل.
7. عند إضافة ملفات جديدة تُعاد الفهرسة تلقائيًا (أقسام، بحث، فلاتر) دون تعديل الكود.
8. الإنترنت يُستخدم حصريًا لفتح روابط الشرح وروابط التواصل (بريد/واتساب).

## 🏗️ البنية (Clean Architecture)

```
lib/
├── core/        → الثوابت، الألوان، الثيم، الأدوات، التعدادات
├── domain/      → الكيانات، واجهة المستودع، حالات الاستخدام
├── data/        → النماذج، مصادر البيانات، الفهرس، تنفيذ المستودع
└── presentation→ الصفحات، الأدوات المرئية، المزوّدات (Provider)
```

- **البيانات**: ملفات JSON (أصول مضمّنة + مجلد استيراد محلي).
- **الإعدادات والمفضلة**: SharedPreferences.
- **إدارة الحالة**: `provider`.
- **Material 3** + خط **Tajawal** مضمّن (يعمل دون إنترنت).
- **RTL كامل** عربي.
