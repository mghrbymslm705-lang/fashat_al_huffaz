# 📄 دليل بنية ملفات المحتوى (JSON Schema)

كل ملف أنشطة JSON يمكن أن يكون بأحد الأشكال التالية:

```json
// شكل 1: قائمة أنشطة مباشرة
[ { "id": "...", "title": "...", ... }, ... ]

// شكل 2: كائن يحتوي على قائمة
{
  "activities": [ { "id": "...", ... } ]
}

// شكل 3: نشاط واحد
{ "id": "...", "title": "...", ... }
```

> - `_doc` حقل إرشادي اختياري يُتجاهل من التطبيق.
> - الملف المسمّى `template.json` لا يُحمَّل كنشاط (قالب فقط).

---

## الحقول

| الحقل | النوع | مطلوب | الوصف |
|-------|-------|:-----:|-------|
| `id` | string | ⚠️ | معرّف فريد. إن غاب يُولَّد تلقائيًا من العنوان والملف. يُستخدم لمنع التكرار |
| `title` | string | ✅ | اسم النشاط |
| `category` | string | ✅ | قسم النشاط: معرّف إنجليزي (`quranic`, `islamic`, `kinetic`, `intelligence`, `group`, `culture`, `kids`, `programs`) أو الاسم العربي (يُترجم تلقائيًا) أو أي قيمة مخصصة (يُنشأ قسم جديد تلقائيًا) |
| `types` | list\<string\> | | أنواع النشاط للمساعد الذكي: `قرآني`, `حركي`, `ثقافي`, `ترفيهي`, `جماعي` |
| `image` | string | | مسار صورة ضمن الأصول، أو رابط خارجي، أو فارغ (يُعرض رمز القسم) |
| `description` | string | | وصف مختصر |
| `goal` | string | | الهدف التربوي |
| `participants` | عدد/نطاق | | عدد المشاركين (انظر النطاقات أدناه) |
| `age` | عدد/نطاق | | العمر المناسب بالسنوات |
| `duration` | عدد/نطاق | | المدة بالدقائق |
| `movement` | string | | `هادئة` أو `حركية` (أو `quiet` / `active`) |
| `location` | string | | `داخل` أو `خارج` أو `داخل أو خارج` (أو `inside` / `outside` / `both`) |
| `tools` | list\<string\> | | الأدوات المطلوبة (فارغ = لا يحتاج أدوات) |
| `steps` | list\<string\> | | خطوات التنفيذ بالترتيب |
| `benefits` | list\<string\> | | فوائد النشاط |
| `tips` | list\<string\> | | نصائح للمشرف |
| `tags` | list\<string\> | | كلمات مساعدة للبحث |
| `videoUrl` | string | | رابط شرح النشاط (يُفتح فقط بضغط "مشاهدة الشرح") |
| `source` | object | | مرجع المصدر الأصلي (الملف، الكتاب، الصفحة) |
| `favorite` | bool | | هل هو من المفضلة افتراضيًا؟ |
| `version` | int | | رقم الإصدار (يُستخدم عند الاستيراد: الأحدث يتجاوز القديم) |
| `isDemo` | bool | | يُعرض كـ "نموذج تجريبي" (اختياري) |

---

## صيغ النطاقات المقبولة

حقول `participants` و `age` و `duration` تقبل أيًا من:

```json
// رقم صحيح
"duration": 15

// نص مفرد
"duration": "15"

// نص نطاق
"participants": "6 - 12"

// نطاق مفتوح
"age": "10+"

// كائن صريح
"participants": { "min": 4, "max": 20 }

// كائن بمفاتيح بديلة
"participants": { "from": 4, "to": 20 }
```

> النطاق غير المحدد يُفسَّر على أنه "يناسب كل الحالات" في الفلاتر والمساعد الذكي.

## ملف الأقسام `assets/data/categories.json`

```json
{
  "categories": [
    {
      "id": "quranic",
      "name": "الأنشطة القرآنية",
      "icon": "menu_book",
      "color": "#22C55E",
      "description": "وصف اختياري"
    }
  ]
}
```

| الحقل | الوصف |
|-------|-------|
| `id` | معرّف القسم (يُستخدم في حقل `category` بالنشاط) |
| `name` | الاسم الظاهر |
| `icon` | اسم أيقونة Material (مثل `menu_book`, `mosque`, `school`...) |
| `color` | لون سداسي عشري مثل `#22C55E` |

> أي `category` غير معرّفة في هذا الملف تُنشئ قسمًا جديدًا تلقائيًا
> (أيقونة ورقم ولون افتراضيان).
